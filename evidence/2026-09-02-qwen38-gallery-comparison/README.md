# Qwen 3.8 gallery comparison evidence

This directory contains the reviewed public evidence for the supervised local
gallery comparison conducted on 2026-09-02.

- `qwen38-27b-q6/browser-final.png` is the final browser capture for the
  Qwen3.8-27B UD-Q6_K_XL candidate.
- `qwen38-flash-q3/browser-final.png` is the final browser capture for the
  Qwen3.8-Flash-Next UD-Q3_K_XL candidate.

Raw controller event streams and state files are deliberately not included.
They can contain full model interaction content. The reviewed configuration,
terminal classifications, interventions, and browser checks are recorded in
the accompanying report.
